 Invoice Billing System

-> Description

A comprehensive Invoice Billing Management System developed using Java, Spring Boot, Spring Security, JWT Authentication, REST APIs, and MySQL. The application enables client management, invoice creation, recurring invoice scheduling, invoice item management, payment tracking, PDF invoice generation, and email notifications.
